# Coding Rules

Do not do more (it's about editing files and executing commands) than you are asked for.
When you believe that the request was incomplete and there is still something to do, describe that in your response and
do nothing until the request is explicitly approved by user.

Do NOT generate or insert any license headers or boilerplate comment blocks.

When adding new file, automatically add it to git as well (unless it's a temp file).

Project documentation is in `docs` directory.
Consult it in case of doubts.

When searching through the source code use CodeGraphContext MCP to sped up the process.
